# Contributing

## Ground Rules

- Only use this project for authorized security testing.
- Keep changes small, reviewed, and covered by tests.
- Do not add network-heavy behavior without policy limits.

## Pull Request Checklist

- [ ] Tests added or updated
- [ ] `pytest` passes
- [ ] `ruff` passes
- [ ] `mypy` passes
- [ ] Security implications considered
- [ ] Documentation updated when behavior changes

## Security Reports

Do not open public issues for sensitive security findings. Contact the maintainers privately when a security policy is published for the repository.
